# 🚀 Resale Marketplace Backend
Бэкенд-система для C2C ресейл-маркетплейса (аналог Avito, Grailed), разработанная на платформе «1С:Предприятие 8.3» в архитектуре **Headless REST API**.

## 🛠 Технологический стек
- **Платформа:** 1С:Предприятие 8.3.
- **Веб-сервер:** Apache 2.4.
- **Интеграция:** REST API (HTTP-сервисы 1С, обмен в JSON).
- **Безопасность:** SHA-256 хеширование, токены `X-API-Key`, TTL сессий, защита от IDOR.

## 🔌 REST API Endpoints
| Метод | Эндпоинт | Описание | Авторизация |
| :--- | :--- | :--- | :--- |
| `POST` | `/auth/register` | Регистрация нового пользователя | Нет |
| `POST` | `/auth` | Вход в систему (SHA-256 проверка пароля) | Нет |
| `POST` | `/auth/change-password` | Смена пароля | `X-API-Key` |
| `GET` | `/lots` | Витрина опубликованных товаров | Нет |
| `POST` | `/orders` | Оформление заказа (холдирование средств, блокировка лота) | Нет |
| `POST` | `/deliveries` | Подтверждение доставки (снятие холда, выплата продавцу -10%) | Нет |
| `GET` | `/user/balance` | Получение баланса по регистру накопления | `X-API-Key` |
| `GET` | `/user/orders` | История заказов текущего пользователя | `X-API-Key` |

## ⚙️ Архитектурные особенности
- **Защита от Race Condition:** Транзакционное проведение документов с Исключительными управляемыми блокировками (`БлокировкаДанных`).
- **Оптимизация СУБД:** $O(1)$ поиск по первичному индексу в регистрах сведений и фильтрация в параметрах виртуальных таблиц остатков.
- **Фоновая рутина:** Регламентное задание автодеактивации просроченных токенов.
